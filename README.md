# Yara AI 💗 — Android app (by Hashim, @hashim_m4x)

## APK build (GitHub)
1. Ee zip extract cheyyuka, ellaa files (.github folder ulppede) oru new GitHub repo yilekku upload cheyyuka (branch: main).
2. Repo > Actions > "Build Yara APK" > Run workflow (push cheythaal automatic aayi run aakum).
3. Finish aayaal run open cheythu "Artifacts" > yara-apk download > extract > app-debug.apk phone il install (Unknown sources allow).
Build fail aayaal error log copy cheythu Claude ku ayakkuka, fix cheythu tharam.

## Use
- Settings (⚙️, top right) > API keys (Gemini / Groq / Claude / custom) ittu kodukkuka.
- 🎙️ amarthiyaal service on: "Hey Yara" ennu vilichu samsarikkam, "Bye Yara" ennu off.
- Overlay reply: Settings > "Draw over other apps" allow + toggle on.
- Battery > Yara unrestricted aakkuka (background il nilkkan).
- Commands: open <app>, whatsapp <text>, call <number>, search <text>.
- Reinstall backup: Android Auto Backup (Google account) + Settings > Export/Import backup.
